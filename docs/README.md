# Документация по библиотеке Geometric lib

## Общее описание решения
**Geometric lib** - библиотека на Python которая нужна для удобного вычисления площади/периметра квадрата(`square.py`), круга(`circle.py`) прямоугольника(`rectangle.py`) и треугольника(`triangle.py`)

## Описание функций 

### 1 Окружность (circle.py)

*   **`area(r)`** - вычисляет площадь круга по его радиусу
    *   **Параметры:** 
      * `r` (*int/float*) - радиус круга
    *   **Возвращает:** 
      * *float* - площадь круга
    *  **Пример:** `area(5)` **Выведет:** `7854`

*   **`perimeter(r)`** - вычисляет длину окружности (периметр круга) по его радиусу
    *   **Параметры:** 
      * `r` (*int/float*) - радиус круга
    *   **Возвращает:** 
      * *float* - длина окружности
    *   **Пример:** `perimeter(5)` **Выведет:** `3142`

### 2 Квадрат (`square.py`)

*   **`area(a)`** - вычисляет площадь квадрата по длине его стороны
    *   **Параметры:** 
      * `a` (*int/float*) - сторона квадрата
    *   **Возвращает:** 
      * *int/float* - площадь
    *   **Пример:** `area(5)` **Выведет:** `25`

*   **`perimeter(a)`** - вычисляет периметр квадрата по длине его стороны
    *   **Параметры:** 
      * `a` (*int/float*) - сторона квадрата
    *   **Возвращает:** 
      * *int/float* - периметр
    *   **Пример:** `perimeter(5)` **Выведет:** `20`

### 3 Прямоугольник (`rectangle.py`)

*   **`area(a, b)`** - вычисляет площадь прямоугольника по двум смежным сторонам
    *   **Параметры:** 
      * `a` (*int/float*) - сторона прямоугольника
      * `b` (*int/float*) - сторона прямоугольника
    *   **Возвращает:** 
      * *int/float* - площадь
    *   **Пример:** `area(5, 4)` **Выведет:** `20`

*   **`perimeter(a, b)`** - вычисляет периметр прямоугольника
    *   **Параметры:** 
      * `a` (*int/float*) - сторона прямоугольника
      * `b` (*int/float*) - сторона прямоугольника
    *   **Возвращает:** 
      * *int/float* - периметр
    *   **Пример:** `perimeter(5, 4)` **Выведет:** `18`

### 4 Треугольник (`triangle.py`)

*   **`area(a, h)`** - вычисляет площадь треугольника по основанию и высоте
    *   **Параметры:**
      * `a` (*int/float*) - сторона треугольника
      * `h` (*int/float*) - высота треугольника
    *   **Возвращает:** 
      * *float* - площадь
    *   **Пример:** `area(4, 5)` **Выведет:** `100`

*   **`perimeter(a, b, c)`** - вычисляет периметр треугольника по трем его сторонам
    *   **Параметры:** 
      * `a` (*int/float*) - сторона треугольника
      * `b` (*int/float*) - сторона треугольника
      * `c` (*int/float*) - сторона треугольника
    *   **Возвращает:** 
      * *int/float*  периметр
    *   **Пример:** `perimeter(3, 4, 5)` **Выведет:** `12`

# Math formulas
## Area
- Circle: S = πR²
- Square: S = a²
- Triangle: S = (a * h)/2
- Rectangle: S = a * b

## Perimeter
- Circle: P = 2πR
- Square: P = 4a
- Triangle: P = a + b + c
- Rectangle: P = 2(a + b)
