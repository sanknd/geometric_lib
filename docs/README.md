# Документация по библиотеке Geometric lib

## Общее описание решения
**Geometric lib** - библиотека на Python которая нужна для удобного вычисления площади/периметра квадрата(square.py) и круга(circle.py)

## Описание функций 

### 1. Окружность (circle.py)

* **area(r)** - вычисляет площадь круга по радиусу r
  * *Пример вызова:* area(5) возвращает 78.54 
* **perimeter(r)** - вычисляет периметр круга по радиусу r
  * *Пример вызова:* perimeter(5) возвращает 31.42

### 2. Квадрат (square.py)
* **area(a)** - вычисляет площадь квадрата по стороне a
  *Пример вызова* area(5) возвращает 25
* **perimeter(a)** - вычисляет периметр квадрата по стороне a
  *Пример вызова* perimeter(5) возвращает 20

# Math formulas
## Area
- Circle: S = πR²
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Square: P = 4a
